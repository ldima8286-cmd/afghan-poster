# «У каждого времени свои герои»

Интерактивный плакат о белорусских воинах-интернационалистах Афганской войны 1979—1989 годов. Городской этап республиканского конкурса.

Плакат рассказывает о пяти Героях Советского Союза, связанных с Беларусью, о хронике войны, минском мемориале «Остров Мужества и Скорби» и о 768 именах, увековеченных на его стенах.

## Что внутри

- пять биографий с модальными окнами и ссылками на источники;
- интерактивная хроника 1979—1989 годов;
- четыре истории мемориала с переключением фотографий;
- «Книга памяти»: поиск по 768 именам, фильтр по буквам, список пропавших без вести;
- раскрывающиеся цифры со ссылками на источники;
- фильм «Афганистан. Я помню» (киностудия «Беларусьфильм») с отложенной загрузкой YouTube;
- адаптивная вёрстка, клавиатурная навигация, поддержка `prefers-reduced-motion`, печатная версия.

Никаких фреймворков, сборщиков и внешних библиотек. Только HTML, CSS и чистый JavaScript.

## Локальный запуск

Открыть `index.html` напрямую в браузере тоже можно, но для предсказуемой проверки локальных путей удобнее поднять простой сервер:

```bash
cd afghan-poster
python3 -m http.server 8000
```

Затем открыть <http://localhost:8000/>.

## Публикация на GitHub Pages

1. Создайте на GitHub пустой репозиторий с именем `afghan-poster` (без README и без .gitignore).
2. В папке проекта выполните:

```bash
git init
git add .
git commit -m "Интерактивный плакат: Беларусь. Афганистан. 1979—1989"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/afghan-poster.git
git push -u origin main
```

3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - **Source:** Deploy from a branch;
   - **Branch:** `main`;
   - **Folder:** `/ (root)`.
5. Нажмите **Save** и подождите 1—2 минуты.
6. Плакат будет доступен по адресу:

```
https://ВАШ_ЛОГИН.github.io/afghan-poster/
```

Файл `.nojekyll` уже добавлен, поэтому GitHub Pages не будет обрабатывать сайт через Jekyll.

## Источники

Все факты, имена и цитаты взяты из белорусских источников. Полный список с ссылками — в разделе «Источники» на самом плакате. Основные материалы:

- Белорусский государственный музей истории Великой Отечественной войны — <https://www.warmuseum.by/>;
- Государственный пограничный комитет Республики Беларусь — <https://history.gpk.gov.by/>;
- Централизованная библиотечная система г. Витебска «Гордость и слава Витебска» — <https://gsv.cbsvit.by/>;
- ОНТ — <https://ont.by/>;
- Белорусское телеграфное агентство — <https://belta.by/>;
- Витебский областной исполнительный комитет — <https://vitebsk-region.gov.by/>;
- электронный ресурс «Афганистан. Без права на забвение» — <https://afgan.vlib.by/>;
- киностудия «Беларусьфильм» — фильм «Афганистан. Я помню».

Фотографии мемориала и портреты Героев публикуются в образовательных целях с указанием источников. Права на изображения принадлежат их правообладателям.

## Технические детали

- Семантическая разметка, `dialog`, `aria-*`, `role="tablist"`, живой поиск.
- Все интерактивные элементы доступны с клавиатуры.
- Видео не загружается до нажатия кнопки — используется `youtube-nocookie.com`.
- Изображения с `loading="lazy"`, ключевое — с `fetchpriority="high"`.
- Цвета, типографика и сетка — в CSS-переменных в начале `css/style.css`.
